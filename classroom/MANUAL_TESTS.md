# Проверка Thonny Classroom в Windows 10/11 x64

Автотесты проверяют создание настоящего окна Tk с плагинами, регистрацию
команд, меню, встроенный Python, исполнение программы и пошаговый протокол
отладчика с переменными. Они не заменяют визуальную проверку мастера установки.

1. Скачать EXE и SHA256SUMS.txt из одного релиза. Сравнить
   `Get-FileHash .\Thonny-Classroom-5.0.0-x64-Setup.exe -Algorithm SHA256`.
2. На обычной учетной записи запустить мастер. Проверить отсутствие запроса
   администратора, выбор каталога, меню «Пуск», выбранный ярлык рабочего стола.
3. Открыть ярлык. При первом запуске выбрать русский язык. Проверить отсутствие
   флага в панели и Support Ukraine в меню «Помощь».
4. В оболочке выполнить `print(20 + 22)` — результат 42. В правом нижнем углу
   выбрать локальный Python из каталога Thonny-Classroom при необходимости.
5. Создать и сохранить файл: `a = 20`, `b = 22`, `answer = a + b`,
   `print(answer)` (каждая команда с новой строки). Выполнить F5.
6. Выполнить Ctrl+F5, шаги F7. Включить «Вид → Переменные» и проверить значения.
7. Если установлен официальный Thonny, убедиться, что оба приложения запускаются,
   а Classroom использует `%APPDATA%\Thonny-Classroom`, официальный — свой профиль.
8. Удалить Classroom через «Установленные приложения». Проверить удаление ярлыков
   и сохранность файлов уроков, официального Thonny и пользовательских настроек.

Установщик не подписан сертификатом издателя; он является неофициальной сборкой.
Профиль и созданные пользователем файлы при удалении сохраняются.
